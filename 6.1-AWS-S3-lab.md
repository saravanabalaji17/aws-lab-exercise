# AWS S3 Hands-on Lab: Bucket, Versioning, Public Access, ACLs, Bucket Policy, and Validation

## Lab Objective

By the end of this lab, you will learn how to:

* Create an S3 bucket
* Create folders
* Upload files
* Enable versioning
* Upload new versions
* Delete and restore objects
* Enable ACLs
* Make objects public using ACL
* Access objects from a web browser
* Disable ACLs
* Make objects public using Bucket Policy
* Block public access
* Validate Access Denied
* Understand the security differences between ACLs and Bucket Policies

# Exercise 13 - Make Object Public Using Bucket Policy

Open:

```
Permissions
```

Select:

```
Bucket Policy
```

Paste the following policy (replace `YOUR-BUCKET-NAME`):

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Sid": "PublicReadObjects",
      "Effect": "Allow",
      "Principal": "*",
      "Action": "s3:GetObject",
      "Resource": "arn:aws:s3:::YOUR-BUCKET-NAME/*"
    }
  ]
}
```

Save the policy.

If **Block Public Access** is still enabled, AWS will prevent you from saving or the policy will not take effect. Disable the bucket-level **Block all public access** setting first.

## Key Concepts Learned

| Feature             | Purpose                                                              |
| ------------------- | -------------------------------------------------------------------- |
| Bucket              | Stores objects in S3                                                 |
| Folder (Prefix)     | Organizes objects logically                                          |
| Versioning          | Protects against accidental overwrite or deletion                    |
| Delete Marker       | Marks an object as deleted without removing previous versions        |
| ACL                 | Legacy mechanism for object-level permissions                        |
| Bucket Policy       | Recommended way to grant bucket/object access                        |
| Block Public Access | Prevents accidental public exposure of data                          |
| Object URL          | Direct HTTPS URL to an object (accessible only if permissions allow) |

This lab takes approximately **60–90 minutes** to complete and covers the most common S3 administration tasks expected in AWS hands-on practice and certification labs.
