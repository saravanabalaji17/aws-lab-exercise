# AWS Application Load Balancer (ALB) with HTTPS Lab Exercise

## Objective

In this lab, you will learn how to:

* Launch **2 EC2 instances**
* Install and configure Apache Web Server (httpd)
* Create the required Security Group
* Request an **SSL/TLS certificate from AWS Certificate Manager (ACM)**
* Validate the certificate using DNS
* Create an **Application Load Balancer (ALB)**
* Configure **HTTP (80) → HTTPS (443) redirect**
* Create a Target Group
* Register both EC2 instances
* Validate using a browser and `curl`
* Stop the Apache service on one server and verify the ALB health check

# Task 9: Validate Using Browser

Copy the ALB DNS name.

Example

```
http://alb-web-123456.ap-south-1.elb.amazonaws.com
```

Expected

```
Automatically redirects to HTTPS
```

Browser URL

```
https://alb-web-123456.ap-south-1.elb.amazonaws.com
```

Refresh several times.

Expected

```
Welcome to Web Server 1

or

Welcome to Web Server 2
```

> **Note:** Because browsers and HTTP clients reuse TCP connections (HTTP keep-alive), repeated refreshes may continue to hit the same backend. The ALB uses its load-balancing algorithm per connection/request, so you may not see perfect alternation.

# Task 14: Validate After Failure

Run

```bash

```

```bash

do

```


Only **Web Server 2** should respond because **Web Server 1** is marked unhealthy.
