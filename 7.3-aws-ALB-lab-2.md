# AWS Application Load Balancer (ALB) Advanced Routing Lab

## Host-Based Routing + Path-Based Routing + HTTPS + ACM + HTTP → HTTPS Redirect

---

# Lab Objective

In this lab, you will learn how to:

* Create **2 EC2 instances**
* Install and configure Apache Web Server
* Host **Website1** on EC2-1
* Host **Website2** on EC2-2
* Create the required Security Groups
* Request an SSL certificate using **AWS Certificate Manager (ACM)**
* Validate the ACM certificate using DNS
* Create an **Application Load Balancer (ALB)**
* Configure **HTTP (80) → HTTPS (443) Redirect**
* Configure **Host-Based Routing**
* Configure **Path-Based Routing**
* Validate routing using a browser and `curl`
* Verify ALB Target Group health checks

---

# Lab Architecture

```text
                               Internet
                                   |
                          web.example.com
                                   |
                    +-----------------------------+
                    | Application Load Balancer   |
                    | HTTP :80  → Redirect HTTPS |
                    | HTTPS :443                 |
                    +-----------------------------+
                                   |
             ------------------------------------------------
             |                                              |
      Host-Based Routing                          Path-Based Routing
             |                                              |
 website1.example.com                              web.example.com/website1
 website2.example.com                              web.example.com/website2
             |                                              |
      ----------------                             ----------------
      |              |                             |              |
TG-Website1    TG-Website2                  TG-Website1    TG-Website2
      |              |                             |              |
   EC2-1          EC2-2                        EC2-1          EC2-2
 Website1        Website2                    Website1       Website2
```

# Task 10 – Configure Path-Based Routing

Add New Rule

Condition

```
Host Header

web.example.com
```

AND

```
Path

/website1/*
```

Action

```
Forward

↓

TG-Website1
```

---

Create another rule

Condition

```
Host Header

web.example.com
```

AND

```
Path

/website2/*
```

Action

```
Forward

↓

TG-Website2
```

Save Rules.

> **Important:** Using both a **Host Header** and a **Path Pattern** in the same rule ensures that only requests for `web.example.com` are evaluated for `/website1/*` and `/website2/*`.

# Validation Summary

| Test                                      | Expected Result                    |
| ----------------------------------------- | ---------------------------------- |
| `http://website1.example.com`             | Redirects to HTTPS                 |
| `https://website1.example.com`            | Website 1                          |
| `https://website2.example.com`            | Website 2                          |
| `http://web.example.com/website1`         | Redirects to HTTPS                 |
| `https://web.example.com/website1`        | Website 1                          |
| `http://web.example.com/website2`         | Redirects to HTTPS                 |
| `https://web.example.com/website2`        | Website 2                          |
| `curl -I http://web.example.com/website1` | HTTP 301 Redirect                  |
| `curl https://website1.example.com`       | Website 1                          |
| `curl https://web.example.com/website2`   | Website 2                          |
| Stop `httpd` on EC2-1                     | TG-Website1 becomes **Unhealthy**  |
| Start `httpd` on EC2-1                    | TG-Website1 returns to **Healthy** |

This lab demonstrates both **Host-Based Routing** (different subdomains routed to different target groups) and **Path-Based Routing** (a single subdomain with different URL paths routed to different target groups), while also implementing HTTPS with ACM and automatic HTTP-to-HTTPS redirection.
